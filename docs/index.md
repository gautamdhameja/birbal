# Birbal

Birbal is a local research agent and architecture learning lab. Its research workflow investigates a question and returns a concise reading list with source links, reasons to read, and key takeaways. Its interactive Architecture Case Lab lets a learner propose an AI-system design before receiving bounded, source-backed challenges and review.

Its implementation keeps the agent loop explicit: model calls, strict JSON protocol parsing, tool dispatch, source search, safe page fetching, structured learning phases, and final-answer rendering. There is no result persistence or publishing subsystem.

Start with [Quickstart](quickstart.md) and [CLI](cli.md). Read [Architecture Case Lab](architecture-case-lab.md) for the learning workflow, then [Architecture](architecture.md), [Agent Harness](agent-harness.md), and [Tools](tools.md) to understand the implementation.
